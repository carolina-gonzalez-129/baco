## Consulta

Al intentar certificar dos traslados de granos mediante un Certificado 1116A, el sistema muestra el mensaje: “Los traslados a Certificar deben tener el mismo Contrato de Acopio”.

## Respuesta

Los traslados tienen asignados contratos de acopio diferentes. Para certificarlos mediante un Certificado 1116A, ambos deben tener asignado el mismo contrato de acopio.

## Pasos a seguir

1. Dirigirse a uno de los traslados de granos involucrados.
2. Modificar el contrato de servicio de acopio desde el campo **Contrato acopio**.
3. Seleccionar el mismo contrato de acopio asignado al otro traslado.
4. Cambiar el contrato de uno u otro traslado según corresponda a la organización.
5. Intentar certificar nuevamente los traslados mediante el Certificado 1116A.

Si el campo **Contrato acopio** no está disponible:

1. Dirigirse al tipo de documento correspondiente.
2. Verificar que el checkbox **Utiliza contrato de acopio** esté tildado.

## Requiere AppBuilder

El usuario debe tener acceso a AppBuilder para verificar o modificar la configuración del tipo de documento.
